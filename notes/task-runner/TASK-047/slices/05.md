# Slice 05 — The receipt is assembled from its sources, for its recipient only

| Tier | critical |
| Covers | AC-2a, AC-2b (limitation), AC-3, AC-4a, AC-4b (content), AC-5 (two recipients; the tenant stated, the sender absent), AC-6a–AC-6e, AC-15 |
| Depends on | slice 02, slice 04 |

## Goal
`ReceiptAssembler::assemble(ReceiptSources): Receipt` is pure and states the envelope from the stream prefix,
the act, the recipient's own evidence, their documents and revision, the boundary, the chain and the
limitations; it reuses `TrailAssembler`'s readings so both documents minimise alike.

## Why
"the envelope's identity and whether it was still open at the boundary, **derived from the stream prefix**,
because `EnvelopeQueryInterface` and `DocumentArtifactChains` answer the present … the hash chain up to the
boundary; the limitations that apply (under `SINGLE_SEAL`, that no per-recipient signature exists). **No other
participant's data.**" (TASK-047 §3 #3)

## The rules (decided here)
- `stream = DecodedStream::read(rows)`; `boundary` = last row → `ReceiptBoundary(type, position, subjectId, occurredAt)`.
- Kind: boundary `SESSION_DECLINED` → `DECLINED`; else `recipient->role->signs()` ? `SIGNED` : `APPROVED`.
- Act fact: `DECLINED` → `firstFor(SessionDeclined, id)`, with `reason` from the event; otherwise
  `firstFor(SignatureCommitted, id)`, with `reservation = TrailAssembler::reservation($event->reservations)`.
  `fact` = `ReceiptFact(type, position, occurredAt)` of that row, empty when none.
- Envelope: title from the first `EnvelopeCreated` event (`Stated`, `LOG`), else `Unstated(NOT_RECORDED_BY_PLATFORM)`;
  `tenantLabel` = `$sources->tenantLabel->mapOr(new Unstated(UnstatedReason::SOURCE_UNAVAILABLE), static fn(string $l)
  => new Stated($l, Source::ROW))`, the same expression `TrailAssembler::envelope()` writes (do not extract it: the
  trail's `envelope()` stays untouched); nothing from `EnvelopeCreated::$senderId`, `EnvelopeSent::$senderId`,
  `EnvelopeClosedBySender` `closed_by`, `EnvelopeVoided` `voidedBy`/`reason` is read;
  `signingMode` = `$sources->signingMode->value`; `closedBefore` = the first row of type `ENVELOPE_VOIDED`,
  `ENVELOPE_CLOSED_BY_SENDER` or `ENVELOPE_COMPLETED` (the event classes' `EVENT_TYPE`s).
- Recipient: id, `stepOrdinal`, `role->value`, `TrailAssembler::authentication($stream, $id)`; personal: name from
  `present($row->fullName)` (`Stated ROW_CURRENT`, else `Unstated NOT_PROVIDED_BY_INTEGRATOR`); `ip`, `userAgent`,
  `acceptLanguage` = `TrailAssembler::observed($act, $evidence, …)` (the act is the decline or the commit row);
  `asserted` only when `$row->signsVia->isDelegated()`, built as `TrailAssembler::party()` builds it; `reported` =
  `Some(TrailAssembler::browserReport(...))` only when the act row's actor kind is `RECIPIENT` and not delegated.
- Documents: `original` = `Stated(Digest('sha256', hash), ROW)` or `Unstated(SOURCE_UNAVAILABLE)`. Revision
  expected iff kind `SIGNED` and mode `SEQUENTIAL_PADES` and the document `signs`; not expected → `None`;
  expected and no source → `Some(Unstated(SOURCE_UNAVAILABLE))`; else `Some(Stated(ReceiptRevision(seq, before
  digest, after digest, bytes, certificate), ROW))` where `bytes` = `NOT_EVALUATED` with no digests, `HOLDS` when
  `whole === artifact->hash` and `prefix(before size) === before->hash`, else `FAILS`; `certificate` = the read-back
  signature whose `signedLength === artifact->sizeBytes` (`Stated BYTES` via `TrailAssembler::certificate`), else
  `Unstated(SOURCE_UNAVAILABLE)`.
- Chain: `Receipt::of(..., array_map(TrailAssembler::fact(...), $stream->facts), ...)`.
- Limitations: exhaustive `match` over `ReceiptLimitationCode::cases()`: `NO_PER_RECIPIENT_SIGNATURE` ⇔ mode
  `SINGLE_SEAL` and kind ≠ `DECLINED`; `APPROVAL_SIGNS_NO_DOCUMENT` ⇔ `APPROVED`; `DECLINE_SIGNS_NO_DOCUMENT` ⇔
  `DECLINED`; `SHARED_PLATFORM_CERTIFICATE` ⇔ a revision is stated; `STATES_THE_ACT_ONLY`, `PLATFORM_CLOCK_TIMES` ⇔ always.

## Reference instance
`TrailAssembler::party()`, `legOutcome()`, `documents()`, `signatureAt()`, `limitations()`, `envelope()` (the
`tenantLabel` expression only; its `createdBy` is exactly what the receipt does NOT state). Tests:

## Prose to write
Class docblock: "Makes the receipt of one recipient's act from its sources, by the rules ADR-0086 §2.3 states. Pure,
like `TrailAssembler`, and never refuses: a missing source is stated as unavailable. The envelope is read from
the stream up to the act, never from Envelope's present. It states the sending organisation by its provisioned
label, as the trail does, and never the person who sent the envelope. The values both documents state are read by
`TrailAssembler`'s own readings, so the receipt minimises a party's evidence exactly as the trail does
(ADR-0072 §2.6)."

## Claims you may NOT copy
- `TrailAssembler`'s "The date is read from the envelope row" (expiry): the receipt states no expiry.
- `EnvelopeSummary`'s creator/sender times and actor: the receipt states the organisation, not who created or sent.
