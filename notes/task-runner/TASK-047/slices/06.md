# Slice 06 — The receipt renders as PDF/A-3a with its JSON attached, behind a renderer of its own

| Tier | critical |
| Covers | V-2, AC-15 (the trail renderer is untouched) |
| Depends on | slice 02 |

## Goal
`Application/Port/ReceiptRenderer` (identity + render) realized by `Infrastructure/Render/TypstReceiptRenderer`,
which compiles the new template `assets/evidence-audit/receipt.typ` with the pinned Typst and attaches the
receipt's JSON byte for byte; `TrailRenderer`, `TypstTrailRenderer`, `TypstCommand` and `trail.typ` unchanged.

## Why
"Rendered PDF/A-3a with its JSON attached by the same pinned Typst binary behind a receipt renderer port of its
own (`TrailRenderer` takes an `AuditTrail` and its adapter binds `trail.typ` alone; both stay unchanged)"
(TASK-047 §3 #3; ADR-0086 §2.3: "a receipt renderer whose `identity()` names the receipt template's digest").

## Files
- Create `src/F5Sign/EvidenceAudit/Application/Port/ReceiptRenderer.php` — `identity(): Result<RendererIdentity,
  TrailRenderFailure>`, `render(Receipt): Result<string, TrailRenderFailure>` (both `#[NoDiscard]`). The failure
  family is reused: its five variants describe the Typst run, not the trail.
- Create `src/F5Sign/EvidenceAudit/Infrastructure/Render/TypstReceiptRenderer.php` — same ctor shape as

## Template content (decided here)
Title "Justificante de actuación"; a note: "Este justificante acredita la actuación de un destinatario en un sobre,
tal como la plataforma la registró hasta ese momento. No recoge datos de otros participantes. Todas las horas están
en UTC. Lleva adjunto el fichero `justificante-<sobre>-<destinatario>.json` con los datos exactos."; sections: Sobre
(id, título, titular — `stated(env.tenant_label)` with the trail's note "Nombre con el que se dio de alta al titular en la
plataforma; no es su razón social." —, modo de firma, cierre registrado o "El registro no recoge ningún cierre del sobre hasta este acto"),
Destinatario (nombre, rol, paso, autenticación), Actuación (tipo, hecho y hora, motivo o reservas), Evidencias,
Documentos (huella original; revisión: secuencia, huellas antes/después, comprobación de bytes, certificado),
Hecho que cierra la actuación (tipo, posición, hora), Cadena (algoritmo, raíz, hojas), Limitaciones, Generación.
`#pdf.attach("/justificante-" + envelope_id + "-" + recipient_id + ".json", bytes, relationship: "data", …)`;
`#set document(author: …)` from `env.tenant_label` exactly as `trail.typ` sets it (an unstated label gives no
author); no row or metadata names the sender. `#metadata(labels) <labels>` with groups `act-kind`, `limitation` (receipt codes), `source`, `unstated-reason`,
`check-outcome`, `assurance-tier`. Limitation wording: `NO_PER_RECIPIENT_SIGNATURE` "En este modo de firma no se
aplica una firma por destinatario: el sobre se sella al terminar."; `APPROVAL_SIGNS_NO_DOCUMENT` "Una aprobación no
añade una firma al documento."; `DECLINE_SIGNS_NO_DOCUMENT` "Un rechazo no añade una firma al documento.";
`SHARED_PLATFORM_CERTIFICATE` "La firma se aplicó con el certificado de la plataforma, no con uno personal.";
`STATES_THE_ACT_ONLY` "Este justificante recoge el sobre tal como constaba al registrarse la actuación; lo ocurrido
después no figura en él."; `PLATFORM_CLOCK_TIMES` "Las horas son las del reloj de la plataforma."

## Prose to write
- Port: "Renders a receipt as a PDF/A-3a document that carries the receipt's JSON form as an attachment
  (ADR-0086 §2.3). The twin of `TrailRenderer` for the second document Evidence & Audit issues; a port because it
  runs an external program. Every failure is a value. Call `identity()` first and build the receipt's `Generation`
  from it." Method docblocks mirror `TrailRenderer`'s with "receipt" for "trail".
- Adapter: "Renders the receipt by running the pinned Typst binary on the receipt template, in a private job
  directory removed before it returns. The job's file names are `TypstCommand`'s, whatever the document: the
  template reads its input as `trail`. The receipt JSON holds the recipient's personal data and is on disk only
  inside the job directory; the child gets an empty environment."

## Claims you may NOT copy
- `TypstTrailRenderer`'s "The trail JSON holds personal data (the D8-minimised group)" — say "the recipient's".
